# Defiende Santo Domingo

Juego web de plataformas. Abre `index.html` en un navegador (o súbelo a GitHub Pages / cualquier hosting estático).

## Cómo jugar
- Flechas ← → para mover, ↑ o Espacio para saltar.
- En el teléfono usa los botones inferiores.
- Salta **tres veces sobre la cabeza** del ratón para recuperarlo todo.
- Pulsa COMENZAR para activar el audio.

## Archivos
- `index.html` — página
- `style.css` — interfaz
- `game.js` — lógica, física y canvas
- `images/hero.png` — jugadora
- `images/mouse.png` — ratón
